Kurzy a spoje

      
Kurz = pořadí spojů, které vůz jede za sebou. Spoj jede po zastávkách svého směru;

Systémy zobrazení

      
Systém zobrazení říká, co ukazují všechny druhy displejů (vnitřní jednořádek, dvouřádek,
        vnější panely). Vozidlo určuje jen, jaké panely má. Soubory jsou ve složce systemy/ pracovní
        složky, podsložky se zobrazí jako skupiny.

Skladba textů

      
Každý údaj je sekvence stránek, které se na panelu překlápějí. Stránka = text, vlastní font
        a mezera, doba zobrazení a podmínka. Jeden běžící text = sekvence s jedinou stránkou.
        Na dvouřádkových panelech se stránka s rolí „nadpis“ zobrazí na horním řádku spolu s následující stránkou.

      

        
        
      

      

        
TextFontMez.sKdyRoleBěž.

        

      
Proměnné: {name} zastávka, {icons} ikony, {zone} číslo zóny,
        {zone_name} název zóny, {destination} cíl, {DESTINATION} cíl velkými písmeny,
        {dest_icons} ikony cílové zastávky, {via} nácestné zastávky (zaškrtnuté „Přes“),
        {via_stop} jedna nácestná zastávka (řádek nácestných: stránka pro každou),
        {next_stop} příští zastávka (i v zastávce), {next_icons} její ikony, {line} linka,
        {time} čas, {message} text mimořádnosti. Ikony i v textu: {icon:vlak}.
        Vnitřní panely: font 0 je tenký, 3 normální (podle fontů v databázi); prázdný font nebo mezera = hodnota
        z „Font / mezera“ výše. Vnější panely: fonty gBUSE0 (0–3 malé, 5 střední, 6–9 velké, 11 drobný); bez fontu si
        panel text naformátuje sám (největší font, který se vejde).

      

    

  






  

    
Nastavení programu

    
Platí pro všechny moduly, ukládá se do nastaveni.yaml v pracovní složce.

    
    
Vypnuto: text, který se nevejde, dostane menší font místo slepení písmen. Platí pro
      vnější panely (automatické formátování) i pro mezery ve formátech vnitřních panelů.

  






  

    

      
Vozidlo a panely

      

        
        
      

      

      

      
Systém zobrazení

      

        
        
      

      
Vozidlo popisuje jen své panely. Co se na nich zobrazuje, určuje systém zobrazení
        (stránka Systémy zobrazení); při jízdě ho jde přepnout v modulu Jízda.

    


    

      
Univerzální databáze panelu

      
Fonty + ikony + čísla linek 1–999. Nahraje se do panelu jednou; všechny texty pak jdou dynamicky
        (volný text v + x9996/x9997).

      
      
      

      

      

      
API pro externí ovládání

      
Např. plugin do OMSI: POST /api/sim/event s {"type": "arrive"} nebo WebSocket
        ws://…/ws/sim (stejné zprávy, odpověď = stav). Typy: start, depart, arrive, next, prev, end, reset,
        message (key / text), clear_message, goto (index), next_trip.
        Výběr spoje: POST /api/sim/trip s {"course": "1", "index": 0} nebo {"direction": "A"}.
